# QSX AI Website

A static responsive landing page for QSX AI, built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — language switch (English/Arabic), mobile navigation, current year

## Preview locally
Open `index.html` in a browser. For the best local development experience, use VS Code with the Live Server extension.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a **public** repository named `qsx-ai-site` (or any name you prefer).
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for the deployment status and open the URL GitHub provides.

The website uses `qsxai.team@gmail.com` as its contact email. Replace it in `index.html` if you choose a different address. No form submission backend or analytics is configured yet; Google Forms can be added later.
