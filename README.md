# QSX AI website

Vanilla HTML, CSS and JavaScript, flat file structure (all files in the repo root). No build step.

Files: index.html, styles.css, config.js (your contact details), i18n.js (English/Arabic copy), main.js, favicon.svg, .nojekyll

Edit `config.js` and set `email` and `whatsapp` (digits with country code, no +).
